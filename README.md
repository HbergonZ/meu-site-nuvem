# Meu Site Nuvem

Este é um site estático criado para promover jogos indies independentes. O site foi desenvolvido usando HTML, CSS, Bootstrap e JavaScript.

## Como Executar

1. Clone este repositório.
2. Abra o arquivo `index.html` no seu navegador.

## Personalização

- Substitua as imagens na pasta `assets/images/` pelas suas próprias imagens.
- Edite o conteúdo do `index.html` para refletir as informações dos seus jogos.
